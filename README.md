# SNS 온라인 그루밍 탐지를 위한 딥러닝 NLP 및 OCR 모델
[![DOI](https://img.shields.io/badge/DOI-10.32604/cmes.2025.061653-blue)](https://doi.org/10.32604/cmes.2025.061653)

본 프로젝트는 소셜 네트워킹 서비스(SNS) 상에서 발생하는 온라인 그루밍 대화를 탐지하기 위한 딥러닝 기반 자연어 처리(NLP) 및 광학 문자 인식(OCR) 프레임워크를 제안합니다. 이 연구는 한국어 구어체 처리에 특화된 **KcELECTRA** 모델과 OCR 기술을 통합하여 SNS 대화 이미지로부터 텍스트를 추출하고, 그루밍 관련 유해성을 높은 정확도로 분류합니다.

## 📄 프로젝트 개요

SNS의 익명성을 악용한 온라인 그루밍 범죄는 아동 및 청소년에게 심각한 위협이 되고 있습니다. 기존 연구는 주로 영어 텍스트에 집중되어 있어 한국어 SNS 환경의 독특한 언어적 특성을 반영하지 못하는 한계가 있었습니다.

본 연구는 이러한 문제를 해결하기 위해 다음과 같은 새로운 접근 방식을 제안합니다.

1.  **OCR과 NLP의 통합**: SNS 대화 스크린샷 이미지에서 텍스트를 정확하게 추출(OCR)하고, 이를 딥러닝 모델로 분석(NLP)하는 통합 프레임워크를 구축합니다.
2.  **한국어 특화 모델 활용**: 구어체, 신조어, 오타가 많은 비정형적인 한국어 SNS 데이터 처리에 뛰어난 성능을 보이는 **KcELECTRA** 모델을 미세조정(fine-tuning)하여 사용합니다.
3.  **높은 탐지 정확도 달성**: 실험 결과, 제안된 모델은 **0.953**의 높은 정확도를 기록하며 기존 트랜스포머 기반 모델들을 능가하는 성능을 보였습니다.

이 프레임워크는 온라인 그루밍 텍스트를 보다 정확하게 탐지하고 관련 범죄를 예방하는 데 기여할 것으로 기대됩니다.

## ✨ 주요 특징

-   **이미지 기반 탐지**: SNS 대화 이미지를 직접 입력받아 그루밍 여부를 판단합니다.
-   **고성능 한국어 처리**: 한국어 구어체 및 비정형 텍스트에 강한 `KcELECTRA` 모델을 사용하여 문맥적 뉘앙스를 효과적으로 파악합니다.
-   **다중 클래스 분류**: 대화 내용을 '성적(Sexual)', '일반(Normal)', '혐오(Hate)' 3가지 클래스로 분류합니다.
-   **뛰어난 일반화 성능**: 학습에 사용되지 않은 **완전히 새로운 데이터**에 대해서도 높은 탐지 성능을 입증했습니다.
-   **실용성**: 일반적인 소비자 수준의 컴퓨팅 환경에서도 효율적으로 동작하도록 설계되어 실제 서비스에 적용하기 용이합니다.

## 🛠️ 기술 스택 및 요구사항

본 프로젝트의 OCR 기능은 Tesseract 엔진을 활용합니다. 따라서 프로젝트를 실행하기 전에 시스템에 Tesseract를 설치해야 합니다.

### 필수 설치

-   **Python 3.9+**
-   **PyTorch**
-   **Pytesseract**
-   **OpenCV-Python**

### Tesseract 설치
#### Windows
1.  [Tesseract 공식 설치 프로그램](https://github.com/UB-Mannheim/tesseract/wiki)을 다운로드하여 설치합니다.
2.  설치 과정에서 "Additional language data"를 선택하여 한국어(`kor`)를 포함한 필요한 언어팩을 설치합니다.
3.  시스템 환경 변수 `PATH`에 Tesseract 설치 경로(예: `C:\Program Files\Tesseract-OCR`)를 추가합니다.

설치 후, Python 코드에서 Tesseract 실행 파일의 경로를 다음과 같이 지정해야 할 수 있습니다.

```python
import pytesseract

# Windows 사용자의 경우
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
path = './ocr_test2.jpg'
image = cv2.imread(path)
rgb_image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

text = pytesseract.image_to_string(rgb_image, lang='kor+eng')
print(text)
```

## 📈 모델 구성 및 성능

### 1. 데이터셋
모델 학습을 위해 AI-Hub의 `한국어 SNS 데이터`, `텍스트 윤리 검증 데이터`와 HuggingFace의 `한국어 혐오 발언 데이터` 등 대규모 한국어 데이터셋을 사용했습니다.

-   **학습(Training)**: 55,657 문장
-   **검증(Validation)**: 27,379 문장
-   **테스트(Testing)**: 9,276 문장

### 2. 모델 아키텍처 및 OCR 과정
본 연구의 핵심 모델인 **KcELECTRA**는 효율적인 학습 구조를 통해 한국어 비정형 텍스트를 효과적으로 처리합니다. 또한, 정확한 텍스트 추출을 위해 Grayscale 변환, 이진화, Closing 연산 등 5단계의 OCR 전처리 과정을 거칩니다.
1. Grayscale 변환: 이미지의 픽셀 정보를 단순화하여 연산 복잡도 감소.
2. 형태학적 변환 (Gradient): 텍스트 경계선을 강조하여 명확하게 만듦.
3. 이진화 (Otsu's Method): 텍스트와 배경을 명확히 분리.
4. Closing 연산: 끊어진 문자 부분을 연결하여 인식률 향상.
5. 관심 영역(ROI) 지정: 텍스트가 밀집된 영역만 추출.

### 4. 일반화 성능 평가 (새로운 데이터셋)

모델의 실사용 성능과 일반화 능력을 검증하기 위해, **학습 및 평가 과정에 전혀 사용되지 않은 새로운 데이터셋(`new_textdata`)**을 별도로 수집하여 성능을 측정했습니다. 이 데이터셋은 실제 온라인 환경을 반영하기 위해 아래와 같은 다양한 출처에서 수집되었습니다.
- **일반 대화**: 카카오톡 대화 로그
- **성적 대화**: PJZC 그루밍 데이터셋 (번역 및 검수)
- **혐오 발언**: Kaggle의 한국어 혐오 발언 데이터셋

모델 재학습 없이, 기존에 학습된 모델로 이 새로운 데이터를 분류한 결과는 다음과 같습니다.

| 모델 (Model) | 정확도 (Accuracy) | 정밀도 (Precision) | 재현율 (Recall) | F1-Score |
|:-------------|:----------------:|:------------------:|:---------------:|:----------:|
| RoBERTa      | 0.796            | 0.814              | 0.796           | 0.798      |
| DistilBERT   | 0.306            | 0.352              | 0.306           | 0.293      |

이 결과는 제안된 KcELECTRA 모델이 준비된 테스트 환경뿐만 아니라, **완전히 새롭고 예측 불가능한 실제 데이터에 대해서도 매우 안정적이고 신뢰도 높은 탐지 성능을 유지**함을 보여줍니다. 이는 모델의 강력한 일반화 성능을 입증하는 중요한 지표입니다.
